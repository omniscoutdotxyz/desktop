# OmniScout Desktop

Your AI agent can do more than answer questions. OmniScout lets it use the browser and apps on your Mac, so it can help you get things done where you already work.

You choose which agent to connect and when to let it act. Pause new actions whenever you want with **Take control**.

## Get OmniScout

Get OmniScout and follow the guided setup at [omniscout.xyz/desktop](https://omniscout.xyz/desktop).

OmniScout requires an Apple silicon Mac running macOS 12 or later.

If macOS asks you to approve OmniScout the first time you open it, go to **System Settings → Privacy & Security**, choose **Open Anyway**, then confirm **Open**.

## What you can do

- Connect the AI assistant you already use.
- Let it work across your browser and Mac apps.
- See when it is active and pause it when you want to take over.
